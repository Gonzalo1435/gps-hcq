# GPS Hospital de Cauquenes

App web de orientación interior del Hospital de Cauquenes (HCQ): elige dónde estás y a dónde vas, y te guía paso a paso por los pasillos públicos, con planos de los seis niveles.

- Funciona en celular y PC, y se puede instalar como app (ícono propio, uso sin internet).
- Modo fácil por defecto (botones grandes, un paso a la vez); "Modo completo" para el buscador de todos los recintos y el modo técnico.
- Atajos por enlace: `?modo=facil`, `?modo=completo`, `?desde=<id o código SIC>` (ideal para un QR en cada acceso).

Esta carpeta es contenido estático: `index.html` + planos, teselas, íconos y datos. Se publica tal cual con GitHub Pages. Ver `LEEME-instalar.txt`.
